在 Sprout（习惯打卡 App）里加一个「统计」页：

- 入口：习惯列表右上角加一个按钮，点了进入统计页。
- 顶部四个数字：完成率、当前连续天数、累计打卡次数、最长连续天数，每个都标出和上周比涨了还是跌了多少（百分比）。数据来自 `StatsAPI.shared.summary()`。
- 中间一张近 7 天每天打卡次数的柱状图，数据来自 `StatsAPI.shared.lastSevenDays()`。
- 下面一张 GitHub 那样的打卡格子图，显示近 120 天，每天一格，打卡越多颜色越深，数据来自 `StatsAPI.shared.checkIns()`（每次打卡一个时间）。
