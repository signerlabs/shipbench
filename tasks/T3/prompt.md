这是一个美食地图 App 的服务端（TypeScript，Hono，部署在 AWS Lambda 上）。测试用 vitest，全部离线跑，不连 AWS。

App 里的店是从短视频导入的：AI 看完视频，给出店名、菜品和一组标签，存进这家店的帖子里，详情页把标签显示出来。现在标签里混进了很多和吃无关的东西：平台词（「#抖音美食」「dou 来探店」）、达人头衔和流量计划（「美食推荐官」「创作者成长计划」），还有推荐这家店的博主自己的名字。

要求：

1. 新建 `src/lib/post-tags.ts`，导出：

   ```ts
   export interface TagContext {
     influencerName?: string;                   // 推荐者（发视频的博主）名字
     restaurantNames?: Array<string | undefined>; // 店名（可能有几个写法）
     dishNames?: Array<string | undefined>;       // 菜名
   }
   export function sanitizeTags(input: unknown, ctx?: TagContext): string[]
   ```

   规则：
   - 去掉平台词：带「抖音」或「dou」（不分大小写）的标签。
   - 去掉达人头衔和流量计划：带「推荐官」「创作者」「创作人」「达人」「博主」的，以及「扶持计划」「成长计划」这类流量计划。
   - 去掉推荐者本人的名号：推荐者名字（名字后面括号里的补充说明不算）里包含这个标签，并且标签至少占名字一半长度，就当作名号去掉。
   - 但出现在店名或菜名里的标签要留着（有的推荐者就是店家自己的账号，名字里带店名或菜名）；只占推荐者名字一小段的口味词也留着。
   - 去掉首尾空白和开头的 #（可能不止一个），空的丢掉，去重，保持原来的顺序；传进来的不是数组就返回空数组，数组里不是字符串的项丢掉。
2. 新导入一家店、重新刷新已有的店，这两条入库路径写进帖子的标签都要先经过它（推荐者名字、店名、菜名用导入时手上已有的数据）。
3. 补上测试。全部测试都要通过：`npm test`。不删已有的测试。
