这是一个短视频生成脚本（Python 单文件 `hfcut.py`，只用标准库：口播、音效、转场、贴纸，生成 HTML + GSAP 工程再渲染成 MP4）。剧本里用 `vo.at("某个短语")`、`vo.span(...)` 在口播里找这句话的起止秒数，让画面卡在那句话上；口播的逐字时间戳来自语音合成（英文口播）或强制对齐（中文配音）。

问题：做中文配音版时，`vo.at("关注我")` 报「口播里找不到「关注我」」，可口播里明明念了这句。英文口播一直正常。

要求：

1. 修好：中文口播也能按短语找到起止时间。中文没有空格：每个汉字算一个词，中文标点当作词之间的分隔；中英混排（比如「打开 App 就行」，短语里英文前后有没有空格都行）也要找得到。英文口播的拆词结果不能变。
2. 补上测试，用假的逐字时间戳（测试里不要调语音合成接口，没有网络和密钥）。全部测试都要通过：`python3 -m unittest discover -s tests`。
3. 不改公开接口（剧本和测试都直接在用 `Voice`、`Word`、`_words()`），不删已有的测试。
